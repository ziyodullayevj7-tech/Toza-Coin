# User area background

Local forest video and matching poster: [Mist-covered forest and mountainscape, Mixkit](https://mixkit.co/free-stock-video/mist-covered-forest-and-mountainscape-100191/), downloaded under the [Mixkit Stock Video Free License](https://mixkit.co/license/#videoFree).

The silent 720p video is compressed for background playback. The still image remains visible when motion is disabled, reduced motion or data saving is requested, or playback fails. No third-party media request is needed at runtime.
